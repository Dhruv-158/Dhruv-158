# 🚀 Quick Start

```bash
# Clone Repository

git clone https://github.com/yourusername/graphicrm.git

# Move into project

cd graphicrm

# Install dependencies

npm install

# Start development server

npm run dev
```

---

# 🐳 Docker Setup

```bash
docker-compose up --build
```
